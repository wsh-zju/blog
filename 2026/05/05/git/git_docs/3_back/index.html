版本回退

通过之前的练习，你已经学会了修改文件，然后把修改提交到 Git 版本库。每当你觉得文件修改到一定程度的时候，就可以“保存一个快照”，这个快照也就是 commit。

一旦你把文件改乱了，或者误删了文件，还可以从最近的一个 commit 恢复，然后继续工作，而不是把几个月的工作成果全部丢失。

    就可以回退到上一个已提交版本

    • 当然，这个命令使用不同参数也会产生不一样的效果
      • --hard：回退到上个版本的已提交状态
      • --soft：回退到上个版本的未提交状态
      • --mixed：回退到上个版本已添加但未提交的状态
    • 这里的 HEAD 表示当前版本
      • HEAD^ 表示上一个版本，HEAD^^ 表示上上个版本
      • 当然，往上 100 个版本不太可能写100 个^来表示，可以使用 HEAD~100
